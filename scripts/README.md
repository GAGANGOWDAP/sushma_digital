# Scripts & Developer Utilities

This directory contains utility, verification, and maintenance scripts for Sushma Digital Studio.

## Scripts Overview

- `check_svg.py` — Verifies SVG background pattern definitions and XML formatting.
- `check_triangular.py` — Checks triangular lattice background geometry equations and CSS injection.
- `fix_svg.py` — Utility script for optimizing and escaping SVG data URIs.
- `test_encoding.py` — Verifies text and file encodings (UTF-8).
- `update_preview.py` — Generates test HTML previews.
- `scratch/` — Workspace scratch scripts and experimental helpers.
