# Build a Premium Photography Studio Website

Build a **modern, premium, fully responsive Photography Studio website** with a clean, elegant, and visually stunning UI/UX. The website should look luxurious, creative, and professional while maintaining excellent performance and smooth user interactions. Build a complete production-ready website with beautiful layouts, reusable components, modern animations, and industry-standard architecture.

## Technology Stack (Latest Stable Versions)

### Frontend

* Next.js (Latest App Router) **(Preferred)** or React.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* Framer Motion
* React Hook Form
* Zod
* Axios
* TanStack Query
* Lucide React
* Swiper.js
* Embla Carousel
* React CountUp
* React Intersection Observer
* React Hot Toast
* React Icons
* next/image for image optimization
* next/font for optimized typography

## UI Theme

Create a premium luxury photography website.

### Primary Color

* White (#FFFFFF)

### Secondary Color

* Deep Elegant Red (#B91C1C)

Use the red color only for:

* Buttons
* Active navigation
* Hover effects
* Icons
* Badges
* Call-to-action sections
* Highlights

Avoid using excessive red. Maintain a clean and elegant appearance.

### Neutral Colors

* Light Gray (#F8FAFC)
* Border Gray (#E5E7EB)
* Dark Text (#111827)

### Design Style

The website should feel:

* Luxury
* Premium
* Minimal
* Modern
* Elegant
* Creative
* Cinematic

Use:

* Large hero images
* Premium typography
* Plenty of white space
* Rounded cards
* Soft shadows
* Smooth scrolling
* Beautiful Framer Motion animations
* Elegant hover effects
* High-quality photography throughout the website

The website must be fully responsive across:

* Mobile
* Tablet
* Laptop
* Desktop
* Large Displays
